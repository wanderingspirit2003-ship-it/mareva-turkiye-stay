# Mareva

Интерактивный прототип метапоиска отелей, апарт-отелей и вилл в Турции.

Текущая версия демонстрирует пользовательский сценарий, фильтрацию, сортировку, избранное и формирование внешнего поискового перехода. Цены в карточках являются демонстрационными и специально так маркированы.

Подробное техническое задание: [docs/MVP_TECHNICAL_SPEC_RU.md](docs/MVP_TECHNICAL_SPEC_RU.md).
